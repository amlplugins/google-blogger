# @amlplugins/google-blogger

Native `@googleapis/blogger` SDK re-exported under the `@amlplugins` namespace.

> Google Blogger (blogger_v3) — blogs, posts, pages, comments, pageViews, users.

## Install

```bash
npm install @amlplugins/google-blogger
```

## Use

```ts
import { /* named exports from @googleapis/blogger */ } from "@amlplugins/google-blogger";
// or
import sdk from "@amlplugins/google-blogger";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
